# NovaCart

NovaCart is a responsive e-commerce storefront demo for browsing everyday products. It includes a product catalog, search and category filters, sorting, a wishlist, and a shopping bag.

## Features

- Responsive storefront layout
- Product search and category filtering
- Sort by featured, price, or name
- Shopping bag with quantity controls and subtotal
- Wishlist saved in browser storage
- Light and dark themes
- Contact form interface

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Browser `localStorage`
